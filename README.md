# VeryMinimalistWebsitePortfolioTemplate
A minimalist, bilingual single-page portfolio template, with no dependencies or build step. Inspired by [Minimal-Website-Template](https://github.com/MichaelDao/Minimal-Website-Template) by MichaelDao.

---

## ✅ Features
- Single centered "card" portfolio page with a clean design
- One-click language switch, no page reload
- CV link that automatically matches the active language
- Quick links to GitHub, LinkedIn, and email
- Respects the `prefers-reduced-motion` system preference (animations disabled if requested)

---

## 💡 Notes
- All text content (title, bio, badge, labels) is driven by the `dict` dictionary in `i18n.js` — no HTML changes are needed to update the text.
- The site is fully static
